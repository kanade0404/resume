## 主な成果

- **新規事業のBtoB SaaSを、PM・業務委託と社内エンジニア1名（私）の体制で立ち上げました**
  2025年3月に開発を始め、2025年10月に初回リリースしました。
  技術選定、アーキテクチャ設計、AWSのインフラ構築、重いフロントエンドを除く開発を担当し、顧客インタビューにも同席しました。
- **ベンダーとの窓口を担い、不正クリックを導入前の約1/4に減らしました**
  不正クリックが多発するたびに、本番環境でログを手作業で削除していました。
  PMの依頼でアドベリフィケーションツールのベンダーとの窓口を担当し、データ連携の方法と、少しずつ検証する進め方を先に合意しました。
  ドキュメントにない仕様は問い合わせて確認し、クリックの受付時点で除外する仕組みを設計・実装しました。手作業の削除も不要になりました。
- **社内向けLLM機能を設計から担当し、出口の見えない開発は自分から止めました**
  2026年7月に事業部として生成AIの導入が決まり、PMと私の2名で担当しています。
  素材の自然言語検索を2026年7月にリリースしました。実際の検索クエリを確認し、利用者が短い検索語しか入力しないという設計上の課題を特定しました。
  台本・動画のAIタグ付けは、人手のタグを正解にした評価の仕組みまで本番環境に構築しました。ただし出力を使う業務が定まっていなかったため、私から提案して2026年9月に開発を止めました。
  2026年10月からは、動画広告ASPの業務全体のAI化として、タスク管理の自動化と動画生成に取り組んでいます。
  AIの出力を確かめる手段としては、lintとテストが有効でした。PMに開発を任せる運用は、私がコードを理解できなくなったため中止しました。
- **事業部のAI活用を、Bizのメンバーと組んで進めました**
  2025年に、生成AIへの本格的な取り組みを事業部長に提言しました。当時は採用されませんでした。
  AWSのAI BPRワークショップをBizのマネージャーに提案し、2026年9月に開催を実現しました。スコープの調整と技術的な事前準備を担当しました。
  Claude Codeの利用計測基盤を開発し、2026年9月に完成させました。Bizメンバーからの相談にも個別に対応しています。

## 重視していること（上から優先）

1. 経営陣が自らAIを使い倒していて、メンバーもAIを使い倒すことに意欲的である
2. LLM・AIが業務効率化の手段にとどまらず、事業の中核にある、または中核に据えようとしている（アーリーフェーズ歓迎）
3. 次のいずれかに関われる
   - 事業に近い立場で、LLMプロダクトの設計から評価・改善まで
   - AIエージェントを前提にした開発基盤（Platform Engineering）
4. AIエージェントや開発ハーネスについて、対等に議論できるエンジニアがいる
5. エンジニア採用を強化し、組織と事業を大きくしていく段階にある
6. BtoB事業の場合、新規事業の立ち上げでPMFした実績がある、またはPMFに相当するトラクションが出ている（新規事業の進め方について、前提を共有したうえで議論したいため）
