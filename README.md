  素材の自然言語検索を2026年7月にリリースしました。
  実際の検索クエリを確認し、利用者が短い検索語しか入力しないという設計上の課題を特定しました。
  台本・動画のAIタグ付けは、人手で付けた既存のタグを評価データにして精度を確認しています。2026年10月に利用開始の予定です。
- **事業部のAI活用を、頼まれる前に自分から進めました**
  AWSのAI BPRワークショップを事業部に提案し、2026年9月に開催を実現しました。
  スコープの調整と技術的な事前準備を担当しました。事前の打ち合わせでは、工数短縮がユーザーへのどんな価値につながるかを考えるよう促しました。
  Claude Codeの利用計測基盤を開発し、2026年9月に完成させました。トークン数、コスト、スキルやsubagentの使用回数を計測し、主にBizメンバーが見ています。
  Bizメンバーからの相談にも個別に対応しています。
- **本番環境での手作業をなくしました**
  不正クリックが多発するたびに本番環境でログを削除していました。
  ベンダーと連携してクリックの受付時点で除外する形に変え、この作業を不要にしました。
