# 共通: 出典・確度・事実と推測の区別

`company-research` と `industry-research` の全成果物(scratchpad の中間 .md、Notion、Obsidian)に適用する。

## 必須ルール

1. **すべての数値・固有の主張に出典URLと日付**(公開日、無ければ取得日)を付ける
2. 見つからないものは「未確認」と書く。**「確認できない」は「存在しない」ではない**
   (例: 退職エントリが見つからない ≠ 離職者がいない)
3. 推測は推測と明記する(「推測:」「〜と読める」)。事実の文と同じ書き方をしない
4. 仮定値・上限値は「仮定」「上限」と明記する。仮定で置いた浸透率から出した売上を「売上見込み」と書かない
5. 確度ラベルを付ける

## 確度ラベル

| ラベル | 意味 | 例 |
|---|---|---|
| `[照合済]` | 一次情報(公式サイト・官報・決算公告・登記・利用規約・本人の記事)を main または subagent が WebFetch で開いて本文と照合した | 決算公告 PDF の純損失額 |
| `[二次]` | 報道・データベース・まとめ記事など二次情報のみ | 調達額を報じたメディア記事 |
| `[Codex報告]` | Codex CLI が見つけたが、まだ WebFetch で抜き取り照合していない | Codex の探索結果 |
| `未確認` | 探したが見つからない/出典が開けない | 主幹事証券 |

`[Codex報告]` は照合が終わったら `[照合済]` か `[二次]` に付け替える。付け替えずに Notion へ書かない。

## 数値の扱い

- 同じ指標に複数の値がある場合は**併記**し、どれを採用したかと理由を書く(黙って1つに丸めない)
- 記事間で数値が食い違う場合は「食い違う数値」として一覧に残す(外部発信の横断知見に入れる)
- 会社自身の主張(TAM・No.1・導入社数)は「会社主張」と明記し、検証結果を隣に置く
- 通貨・年度・税込/税抜・取扱高/売上の区別を明記する

## 訂正の伝播

調査の後半で前半の事実を訂正したら、その事実が登場する**全箇所**(冒頭サマリ、表、未確認リスト、
面談質問)を直す。前半と後半の矛盾を残したまま書き込まない。
