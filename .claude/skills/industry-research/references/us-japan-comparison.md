# Step 4: 日米スタートアップ比較と日本への示唆

Step 1・2 の結果から、同じ業界の日米スタートアップの違いを7観点で比べる。
出力: `<scratchpad>/i40-comparison.md`。比較は事実(出典付き)と解釈(推測)を分けて書く。

## 比較表

| 観点 | 日本 | 米国 | 違いが生じる理由(推測可、明記) |
|---|---|---|---|
| 市場構造 | 寡占/分散、既存大手の強さ | 同左 | |
| 顧客・チャネル | 直販/代理店/SIer 経由、意思決定者 | 同左(セルフサーブ・PLG の比率など) | |
| 資金調達環境 | ラウンドの典型額、主な投資家(VC・CVC・デット) | 同左 | |
| エグジット | IPO(グロース市場)と M&A の比率 | IPO・M&A・PE ロールアップの比率 | |
| 規制 | 許認可・業法 | 州法・連邦規制 | |
| 技術 | 採用されている技術・AI 活用の度合い | 同左 | |
| 人材 | エンジニア採用の難易度、業界知識を持つ人材の流動性 | 同左 | |

Notion に書くときは `<table>` 記法にする。

## 日本への示唆

比較表から、次の3つを各1〜3行で書く。いずれも推測を含むので「示唆」として書き、断定しない。

1. **米国で起きて日本でまだ起きていないこと**(タイムマシンモデルが成り立つか、成り立たない理由は何か)
2. **日本固有の参入障壁・機会**(商習慣・規制・チャネル)
3. **転職先候補を見るときの論点**: この業界のスタートアップを評価するとき、何を確認すべきか
   (例: エグジットが M&A 中心なら、清算優先権と SO の価値を確認する)

業界DB の「日米スタートアップの違い」列には比較表の要点を3〜5行で要約して入れる。
